# 审美与优化思考过程(心法)

> 本文件是「汇报大师 PPT」的灵魂。规则(铁律)防灾难,心法(本文)出好作品。
> **用户说不清要什么,但一眼认出什么是好** —— 所以一切引导都围绕"给选择、给证据、给小样",绝不给开放题。

## 0. 总纲:美是可诊断的工程

一切"不好看"都能定位到具体根因,不存在"玄学审美"。五维诊断模型:

| 维度 | 一问 | 失衡症状 |
|---|---|---|
| **主次** | 这页的主角是谁?3 秒内能说出来吗? | 乱、堆砌、像 Excel |
| **节奏** | 相邻页的构图不同吗?有轻重呼吸吗? | 呆板、模板脸 |
| **呼吸** | 有没有留白?还是塞满? | 拥挤、压迫 |
| **字体** | 有对撞(衬线×无衬线×mono)与纪律(字阶)吗? | 平淡或混乱 |
| **色彩** | 颜色在做结构还是当墙纸?accent 超 3 个了吗? | 脏、廉价、恶心 |

skill 的所有版式与令牌,都是这五维的具象化。**诊断先于动手**。

## 1. 引导术(用户只会说"做个汇报PPT"时)

### 1.1 摸底(合并一轮问完,禁多轮往返)
受众是谁 / 什么场合 / 有没有现成材料。三个答案决定风格与版式的一半。

### 1.2 风格三选一(附证据,不让用户做填空题)
按受众给 2-3 个风格,每个附一句"为什么适合你":
- 内部汇报/年轻团队 → brutal(张扬、有记忆点)
- 客户/海外/高端 → dark_premium(克制、高级)
- 品牌提案/年度回顾/研究 → editorial(杂志感,最高审美档)
**证据法**:面向特定客户时,去看**客户的品牌审美**(官网/画册/门店)——客户的调性就是风格的证据,不凭自我想象拍颜色。

### 1.3 样片选美法(用户说不上来要什么时的杀手锏)
用同一份内容做 2-3 页不同风格小样(成本几块钱),让用户**指认**。
> 用户认不出"好",但一眼认出"更好"。样片比任何问卷都准。
流程:出样 → 用户选 → 固化成 spec 的风格/版式决策 → 开跑前复述确认。

### 1.4 收敛
把用户的选择写成 spec,渲染前用一句话复述:"我将用 X 风格、Y 版式序列、Z 交互,做 N 页,对吧?"——确认再跑,禁止跑完再返工。

## 2. 诊断表(症状 → 根因 → 处方)

| 症状(用户可能的原话) | 根因 | 处方 |
|---|---|---|
| "丑,但说不上来" | 无设计体系,凭感觉堆元素 | 套风格令牌,让版式说话 |
| "老套/模板脸" | 八股构图(标题+项目符号) | 换版式原型,一页一构图 |
| "颜色恶心/脏" | 配色无纪律(>3 色/高饱和) | 令牌色板;accent 只做标点 |
| "照片被裁/展示不全" | cover 滥用 | 产品/场景用 contain;cover 只给全屏背景 |
| "数字/文字错位" | 旧式数字字体(Georgia 高低不齐) | 等高线字体;错位监测器自动抓 |
| "字太小看不清" | 无字阶概念 | type_scale 吸附;下限 10.5pt |
| "乱/堆砌" | 无主次 | 一页一主角;头条数字制 |
| "呆板/没创意" | 无节奏变化 | 相邻不同版式;插 section/金句换气 |
| "内容假大空" | 数据编造/内容薄 | 结论式标题;深挖结构做厚 |
| "客户无感/不像给他们的" | 未研究客户审美 | 客户的品牌就是风格证据(§1.2) |
| "不像 2026 年的东西" | 过时流派(中式豪华/AI 渐变) | 走 editorial/brutalist 现代路线 |

## 3. 自检术(交付前,agent 自当挑剔客户)

渲染后、交付前,逐页过这 8 问,任一为"否"就修:
1. 这页的主角是谁?(3 秒内能说出)
2. 标题是结论句吗?(不是"概述/介绍"这类空词)
3. 相邻页构图不同吗?
4. 有呼吸(留白)吗,还是塞满?
5. 数字/中英排版整齐吗?(错位监测零报警)
6. 照片完整显示吗?无黑底/白边吗?
7. 目标受众会不适吗?(拼写/文化/语气本地化)
8. 汇报人照着备注能讲吗?(每页有 note)

> 第 8 问是汇报大师的底线:**PPT 是给人讲的,不是给人看的**。

## 4. 迭代法(用户否决时,禁止问"哪里不满意")

用户说不清哪里不好。把负面词映射到层级,用选择题确认:

| 用户原话 | 定位层级 | 动作 |
|---|---|---|
| "丑/恶心/廉价" | 风格层 | 换风格或调令牌 |
| "老套/没创意/呆板" | 构图层 | 换版式原型 |
| "缺内容/太薄" | 内容层 | 补内容,不做样式掩盖 |
| "错位/乱码/溢出" | 执行层 | 引擎护栏修(通常已自动防住) |
| "不像给 XX 的" | 策略层 | 回到 §1.2 找客户审美证据 |

确认用选择题(A 还是 B),不让用户写小作文。

## 5. 审美的来源(学不完,但要有路径)

1. **业界公开资料临摹**:中式豪华汇报图库(密度可学、气质过时=**反例**教材)、
   AI 渐变卡片风(**过时**路线)、现代 editorial/brutalist 风格论文
   (**正例**:字体对撞/结构即装饰/反色焦点/克制用色)。
2. **客户即审美**:客户品牌的官网、画册、门店照片,就是最好的风格教科书。
3. **每次被纠正,往诊断表加一行**——本表是活的,越用越准。

## 6. 一页纸流程(心法落地)

```
摸底(受众/场合/材料)
  → 风格三选一(附证据)或样片选美(2-3 页小样)
  → 复述确认(风格/版式序列/交互/页数)
  → 写 spec(每页:结论式标题+内容+口播备注)
  → preflight(零 E)
  → build(LINT/错位监测零警告)
  → COM 导出逐页目检 + 自检 8 问
  → 交付(说明交互与备注位置)
```
